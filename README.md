# Manufacturing Downtime Analysis

## 📌 Project Overview
This project focuses on analyzing and predicting manufacturing downtime in a drinks production environment. It was developed as a graduation project under the **Digital Egypt Pioneers Initiative (DEPI)**, aiming to transform raw production data into actionable insights that support operational efficiency, downtime reduction, and data-driven decision-making.

The study combines data cleaning, exploratory analysis, KPI evaluation, and basic predictive modeling to identify the main drivers of downtime and assess the feasibility of short-term downtime forecasting.

---

## 🎯 Project Objectives
- Analyze historical downtime data to identify key causes and patterns  
- Evaluate downtime behavior across products, shifts, and production lines  
- Apply data cleaning and wrangling techniques to prepare reliable datasets  
- Develop simple prediction models to estimate next-day downtime  
- Present insights using interactive dashboards and clear visualizations  

---

## 📂 Dataset Overview
The project uses a manufacturing downtime dataset that were provided in 4 excel sheets:
- Line Productivity
- Products
- Downtime Factors
- Line Downtime

The dataset was preprocessed to resolve missing values, inconsistent formats, and structural issues before analysis.

---

## 🔄 Methodology & Workflow
1. **Data Cleaning & Wrangling**
   - Handled missing and inconsistent values
   - Standardized formats and variables
   - Built a structured data model for analysis

2. **Exploratory Data Analysis (EDA)**
   - KPI calculation (total downtime, average downtime)
   - Trend analysis over time
   - Pareto analysis to identify major downtime contributors
   - Comparison across products, shifts, and operators

3. **Prediction & Modeling**
   - Linear regression models tested using Excel and Python
   - Predictors included date-related features and downtime factors
   - Model performance evaluated using R² and error metrics

4. **Visualization & Reporting**
   - Interactive dashboards built in Power BI and Tableau
   - Final insights summarized in a presentation and documentation report

---

## 🛠 Tools & Technologies
- **Excel**: Data cleaning, regression testing, exploratory analysis  
- **SQL**: Data querying, filtering, and logical structuring  
- **Python (Pandas, Scikit-learn)**: Predictive modeling and analysis  
- **Tableau**: Visual analytics and comparative dashboards  
- **Power BI**: Interactive dashboards and KPIs
  
---

## 📊 Key Insights & Results
- A small number of downtime factors contribute to a large portion of total downtime (Pareto effect)
- Operator-related downtime shows clear variation across shifts
- Predictive models were able to capture partial trends, but accuracy remained limited due to data size and noise
- Results highlight strong potential for improvement through operational and data-driven interventions rather than full automation
